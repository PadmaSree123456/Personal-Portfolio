# Personal-Portfolio
Personal portfolio website built with HTML and CSS showcasing my skills, educational background, software development projects, and contact details.

---

##  Features

- **Sections Included**:
  - **About Me**: Brief personal introduction and objectives.
  - **Education**: Details about degree and coursework.
  - **Skills**: Core programming languages and technical tools.
  - **Projects**: Portfolio showcase with highlights.
  - **Contact**: Quick links to connect.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3
- **Icons**: Font Awesome
- **Fonts**: Google Fonts (Inter)

---

## 📁 How to View

1. Clone or download this repository.
2. Open `index.html` in any modern web browser (Chrome, Edge, Firefox, etc.).
